# Responsive UI Rules

- Build mobile-first with the existing Tailwind breakpoints.
- Preserve established desktop layout patterns.
- Stack form grids and action groups when the viewport is narrow.
- Allow headings and labels to wrap.
- Preserve the existing mobile Sheet/sidebar behavior.
- Avoid accidental page-wide horizontal overflow.
- Use the existing table overflow approach for wide data.
- Keep icon buttons stable and accessible.
- Test narrow and wide layouts for user-facing changes.
- Check long labels, loading, empty, validation, and error states where relevant.
